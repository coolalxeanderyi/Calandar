# 外接大腦

（網站裡的標題還是「計劃版」，在設定裡可以自己改；加到手機主畫面、瀏覽器分頁上看到的名字是「外接大腦」。）

把任務、行事曆、目標、習慣、購物清單和記帳放在同一個網站裡，用 Google 帳號登入後，手機和電腦的資料會自動同步。
版面參考 Notion 的 Planner OS 模板：上方是封面和分頁按鈕，下面是一塊一塊的區塊。
可以從 30 套配色主題裡挑喜歡的，也可以跟 Google 日曆自動雙向同步（iPhone 的「行事曆」也看得到）。

網站網址（開啟 GitHub Pages 之後）：<https://coolalxeanderyi.github.io/Calandar/>

網址只有這一個。網站更新時直接改這裡的檔案，打開著的網站會自己換成新版。以前的 `/v1/`～`/v7/` 網址已經拿掉了，打開會自動回到首頁。

## 功能

- **總覽**：小日曆會跟你打招呼（「早安，名字！」再加一句依時間挑的話，例如「吃飯了嗎？」「好好休息」，每個時段二、三十句，全部看過一輪才會重複；名字在設定裡改），今天和逾期的任務、本週任務（可依優先度篩選）、今天的心情和一句話、今天的習慣、進行中的目標、小月曆。逾期的任務可以一鍵「全部移到今天」或「全部延到明天」（可以復原）
- **重要日子（倒數日）**：總覽上一排小卡，例如「回台灣 還有 9 天」「多益考試 還有 25 天」。分四種：倒數（考試、出國這種一次性的日子）、生日和紀念日（每年同一天，自動算下一次還有幾天、滿幾歲、第幾週年）、正數（從那天開始算第幾天，例如開始運動）。今天是生日的話小日曆會跟你說「今天是媽媽生日！」。連接 Google 日曆之後會放進日曆，前一週和前一天早上 9 點提醒，生日和紀念日每年都會提醒
- **朋友**：記朋友的生日、關係、喜歡和不喜歡的東西、送禮點子。打「小美 3/14 #同學 喜歡貓、抹茶」就加入，不知道年份只打月和日。30 天內生日的排在最上面，可以用名字或喜歡的東西找人（例如找「貓」）。14 天內的生日會出現在總覽的「重要日子」，當天小日曆會說「今天是小美生日！」；連接 Google 日曆後，每年生日前一週和前一天提醒，說明裡寫著他喜歡什麼
- **天氣**：小日曆的泡泡裡會說今天的天氣，例如「倫敦現在 8°C，今天 5～10°C，會下雨，記得帶傘、穿暖一點」；晚上 6 點以後改說明天的天氣。地點在設定裡搜尋城市，或用現在的位置。資料來自免費的 [Open-Meteo](https://open-meteo.com/)，不用申請帳號，查到的天氣存在裝置裡 30 分鐘，不會一直去問
- **手機滑動手勢**：任務和購物清單往右滑是完成（再滑一次取消），往左滑是刪除（可以按「復原」）。重複的任務不能用滑的刪，要點開來刪，免得整串都不見
- **字體大小**：設定 → 外觀 → 字體大小，有標準、大、特大、超大。只改那一台裝置，例如 iPad 調大，手機維持原本的大小
- **快速新增**：直接打「明天下午3點 家教 #工作」，就會自動設好日期、時間和標籤，輸入時下面會先顯示會加上什麼。看得懂今天／明天／後天、週五、下週二、12/3、12月3日、15號、今晚、早上9點、下午3點半、19:30、1小時、半小時、#標籤、!高
- **標籤**：自己建立標籤（例如家教、拍片、學校），名稱和顏色都可以改，一個任務可以有好幾個。任務頁和行事曆可以用標籤篩選；在設定裡管理，刪掉標籤不會刪掉任務
- **任務**：依「逾期／今天／明天／接下來 7 天／之後／沒有日期」分組，可以設日期、時間、時長、優先度、狀態、標籤、提醒時間、備註，並連到某個目標。新增任務時日期預設是今天（不想排日期就把日期清掉，會放在「沒有日期」，那一組可以一鍵「全部排到今天」）。每個任務旁邊可以直接按「待辦／進行中／完成」切換狀態（重複的任務是每一次分開打勾）
- **看板**：任務頁可以切換成「待辦／進行中／完成」三欄的看板，電腦上直接拖卡片，手機上用箭頭移動（重複的任務只在清單裡）
- **任務範本**：常用的任務（例如拍片流程的小清單）可以「存成範本」，之後新增任務時「從範本建立」
- **提醒**：每個任務可以選提醒時間（準時、前 5／10／30 分鐘、前 1 小時、前一天），透過 Google 日曆通知手機
- **重複任務**：每天、每週幾、每月同一天，可以設定重複到哪天。每一次分開打勾，清單裡只顯示今天和下一次，不會堆成一堆逾期
- **小清單**：任務裡可以列小步驟，任務列會顯示做了幾項（例如 ☑ 2/5）
- **搜尋**：任務頁的搜尋會一起找備註、小清單和目標名稱；在電腦上按 <kbd>/</kbd> 可以直接跳到搜尋框
- **行事曆**：月、週、日三種檢視。日檢視是一小時一格的時間軸，看得出哪裡有空檔，點空白的時段就能在那個時間新增任務；在時間軸上拖曳任務可以改時間、拉方塊底部可以改長度，整天或還沒排日期的任務也可以直接拖進時間軸（手機請先長按再拖）。電腦上可以把任務直接拖到別天（重複的任務除外）
- **購物清單**：打「牛奶 2瓶 #全聯」就會加入，會依名稱自動分到類別（蔬果、肉類海鮮、乳製品和蛋…），也可以自己選類別或打「#類別名稱」；「#店家」記店家、「2瓶」「x2」是數量、「120元」是價錢，括號裡的字或旁邊的「備註」欄是備註；按「詳細」可以一欄一欄填。可以依類別或依店家分組、依店家篩選、看預估要花多少、「複製清單」貼到 LINE。類別可以在「管理類別」或選類別的地方自己新增、改名、刪除（跟記帳簿的類別分開）。買到了打勾，提示裡按「記帳」就會順便記到記帳簿（會換成記帳簿的類別，例如蔬果 → 飲食）
- **記帳簿**：打「午餐 8.5」「家教 +40」「昨天 超市 23.9 #日用品」就記好了，會自己猜類別（猜錯可以按「修改」）。每個月的支出、收入、結餘，每月預算還剩多少、平均每天可以花多少，錢花在哪些類別，以及最近 6 個月的支出。金額一律用新台幣。記帳的類別（支出、收入分開）可以在「預算、類別」或記一筆的視窗裡自己新增、改名、刪除，跟購物清單的類別分開
- **每週回顧**：這週完成了哪些事、還有什麼沒做、時間花在哪些標籤、每天的心情、這個月的心情起伏（折線圖，移到或點某一天可以看那天的心情、做了什麼、花了多少錢；下面每週一行：平均心情、完成幾件、花了多少）、每個習慣打卡了幾天，再寫下做得好的事、可以更好的地方和下週的三個重點（可以一鍵變成下週的任務）
- **目標**：依領域分組，進度可以依「相關任務完成比例」自動計算，或自己調整；顯示還剩幾天
- **習慣**：每週打卡表、目前連續天數、最長連續天數、本月完成率，以及最近 15 週或一整年的打卡紀錄
- **換主題**：頁首的主題按鈕（例如 🍓）可以從 30 套配色裡挑，分成七類：
  - 四季：春天、夏天、秋天、冬天
  - 櫻花：夜櫻、櫻花糰子、櫻吹雪
  - 楓葉：紅葉、紅葉山谷、楓糖
  - 飲料：草莓牛奶、抹茶拿鐵、珍珠奶茶、海鹽汽水、檸檬蘇打、蜜桃烏龍、橘子汽水、熱可可
  - 甜點和水果：藍莓優格、薄荷巧克力、西瓜冰、蜂蜜鬆餅、棉花糖
  - 自然和節日：星空、蘑菇森林、扶桑花、聖誕節、彩虹
  - 簡約：黑白簡約、莫蘭迪

  每一套都有淺色和深色版本，點一下就能先預覽，吉祥物、紙膠帶、按鈕和彩紙都會跟著換顏色
- **封面**：32 種用程式畫的封面（雲朵、野餐格紋、糖霜彩針、珍珠奶茶、波點、海浪、檸檬片、星空、西瓜、橘子汽水、熱可可、聖誕、蘑菇、扶桑花、棉花糖、鬆餅、彩虹、莫蘭迪色塊、櫻花、向日葵、落葉、雪天、夜櫻、櫻花糰子、櫻吹雪、紅葉、紅葉山谷、楓糖，以及農田、海灘、梯田、沙丘空拍），格紋、彩針和波點會跟著主題換顏色
- **Google 日曆同步**：Google 日曆裡的行程會出現在計劃版；有日期的任務、目標期限和重要日子會放進 Google 日曆裡一個叫「計劃版」的日曆（只動這個日曆，不碰你其他的行程）。有時間的任務用設定裡的「行程的時區」放進日曆，每台裝置都一樣；裝置換了時區（例如回台灣）時，頁首會問要不要改成當地時間
- **每天自動備份**：連接 Google 日曆之後，每天會自動備份一份到你的 Google 雲端硬碟的「計劃版備份」資料夾，留最近 30 天
- **其他**：完成任務和打卡時的彩紙動畫、手機版的底部分頁列、可直接點標題改名、匯出／匯入備份、刪除後可以按「復原」、在電腦上按 <kbd>N</kbd> 可以快速新增任務
- **自動更新**：每次打開、回到這個分頁，或每 5 分鐘，網站都會檢查有沒有新版本，有就自動換過去；正在輸入或開著視窗時會先問你
- **離線也能用**：打開過一次之後，沒有網路也打得開網站，照樣可以新增和打卡，連上網路後自動同步。也可以加到手機主畫面，用起來像 App

## 第一次設定（大約 10 分鐘）

網站本身放在 GitHub Pages，資料放在 Firebase。兩邊都用免費方案就夠了，不需要信用卡。

### 1. 開啟 GitHub Pages

1. 打開這個 repo 的 **Settings → Pages**
2. **Source** 選 **Deploy from a branch**
3. **Branch** 選 `main`，資料夾選 `/ (root)`，按 **Save**
4. 等一兩分鐘，網站就會出現在 <https://coolalxeanderyi.github.io/Calandar/>

這時候打開網站，會看到「連接 Firebase 之後就能開始用」的畫面，也可以先按「先試用」看看（試用模式的資料只存在那台裝置）。

### 2. 建立 Firebase 專案

1. 到 [Firebase 主控台](https://console.firebase.google.com/)，按「建立專案」，名稱隨意（例如 `my-planner`）。Google Analytics 可以關掉。
2. 在專案首頁按網頁圖示 **`</>`**（新增網頁應用程式），取個名字後按「註冊應用程式」。不用勾 Firebase Hosting。
3. 畫面上會出現一段 `const firebaseConfig = { ... }`，先把它複製下來。

### 3. 把設定貼進 `firebase-config.js`

打開 repo 根目錄的 [`firebase-config.js`](firebase-config.js)，把剛剛複製的值填進對應的欄位，例如：

```js
export const firebaseConfig = {
  apiKey: 'AIza...',
  authDomain: 'my-planner.firebaseapp.com',
  projectId: 'my-planner',
  storageBucket: 'my-planner.firebasestorage.app',
  messagingSenderId: '1234567890',
  appId: '1:1234567890:web:abcdef',
};
```

這些值本來就會出現在網頁上，公開是正常的；真正保護資料的是下一步的安全規則。

### 4. 開啟 Google 登入

1. Firebase 主控台左側選 **Authentication（驗證）** → 「開始使用」
2. **Sign-in method（登入方式）** → 選 **Google** → 啟用 → 選一個支援用的 email → 儲存
3. **Settings（設定）** → **Authorized domains（授權網域）** → 新增 `coolalxeanderyi.github.io`

### 5. 建立資料庫並貼上安全規則

1. 左側選 **Firestore Database** → 「建立資料庫」
2. 位置選離你近的地方（例如 `europe-west2` 倫敦，或 `asia-east1` 台灣），之後不能改
3. 選「以正式版模式啟動」
4. 建立好之後切到 **規則（Rules）** 分頁，把 repo 裡 [`firestore.rules`](firestore.rules) 的內容整個貼上，按「發布」

這份規則的意思是：每個人只能讀寫自己帳號底下的資料。

### 6. 推上 GitHub，登入

把改好的 `firebase-config.js` commit 並 push。等 GitHub Pages 更新完（一兩分鐘），重新整理網站，按「用 Google 登入」就完成了。

如果你之前在這台裝置用過試用模式，第一次登入時網站會問要不要把試用資料搬到帳號裡。

### 7.（選用）同步 Google 日曆

連接之後會自動雙向同步，不用再按任何按鈕：

- 你 Google 日曆裡的行程，會出現在計劃版的行事曆和「今天」（只會讀，不會改你其他的日曆）
- 計劃版有日期的任務和目標期限，會放進 Google 日曆裡一個叫「計劃版」的日曆

做法是在自己的 Google 帳號裡放一小段免費的程式（Google Apps Script）當橋樑。網站裡有一步一步的說明：登入後打開 **設定 → Google 日曆**，照著做一次就好（大約 5 分鐘，建議用電腦）：

1. 按「複製程式碼」。程式碼裡有一組只屬於你的密碼，不要給別人。
2. 打開 [Apps Script](https://script.google.com/home)，按「新專案」，把原本的內容刪掉、貼上程式碼、儲存。專案名稱可以改成「計劃版同步」。
3. 左邊「服務」旁邊按「＋」，加入「Google Calendar API」。
4. 「部署」→「新增部署作業」→ 類型選「網頁應用程式」，執行身分選「我」，誰可以存取選「所有人」，按「部署」。
5. 授權時會看到「Google 尚未驗證這個應用程式」，因為這是你自己剛貼上的程式，按「進階」→「前往 計劃版同步（不安全）」→「允許」。權限裡會有 Google 日曆和 Google 雲端硬碟；雲端硬碟是用來每天備份的，程式只會在「計劃版備份」資料夾裡放備份檔。
6. 把「網頁應用程式」的網址（結尾是 `/exec`）貼回計劃版，按「連接」。

連接之後可以在設定裡勾選要顯示哪些日曆。之後網站更新，大部分時候都不用動 Apps Script；如果設定裡提醒「Apps Script 的程式有新版本」，照提示重新複製、貼上，在函式選單選 test 按「執行」允許權限，再到「部署 → 管理部署作業 → 編輯 → 新版本」更新一次就好（網址不會變）。

**每天自動備份到雲端硬碟**：用第 2 版以後的 Apps Script 程式碼，計劃版每天第一次打開時，會在背景把全部資料（不含 Apps Script 的網址和密碼）存成 `計劃版備份 2026-12-01.json` 這樣的檔案，放在雲端硬碟的「計劃版備份」資料夾，同一天會覆蓋同一個檔案，只留最近 30 天。設定裡可以關掉、立即備份或打開資料夾；要還原時，在設定裡「匯入備份」選那個檔案就好。

同步的規則：

- 有日期的任務會變成行程。有時間的照設定的時長（預設 1 小時），預設開始前 10 分鐘提醒（每個任務可以自己選提醒時間）；沒有時間的是全天行程，預設不提醒（可以選前一天晚上 9 點）
- 任務的標籤會寫在行程說明的第一行，例如「#家教 #工作」
- 進行中目標的期限會變成全天行程（名稱前面有 🎯）
- 完成的任務名稱前面會加上 ✅，顏色變灰，也不會再提醒
- 重複的任務會變成 Google 日曆的「重複行程」；每一次分開打勾只記在網站上
- 「計劃版」日曆請在網站上修改；在 Google 日曆裡直接改的話，下次同步會被蓋回來。Google 日曆裡其他的行程，計劃版只會讀，想變成可以打勾的任務，點開行程按「變成任務」

**另一種方式（不用 Apps Script）**：設定裡的「其他方式」可以直接用 Google 登入連接，但只會把任務放進 Google 日曆、看不到 Google 日曆的行程，而且 Google 給的通行證大約一小時就過期，有新的變更時要再按一次。用這個方式之前，要先在 Google Cloud 打開 [Google Calendar API](https://console.cloud.google.com/apis/library/calendar-json.googleapis.com?project=calender-6f8ad)，並在 [資料存取](https://console.cloud.google.com/auth/scopes?project=calender-6f8ad) 加入 `https://www.googleapis.com/auth/calendar.app.created` 這個範圍。

**想在 iPhone、iPad 的「行事曆」App 看到**：在 iPhone 的「設定」裡把同一個 Google 帳號加入「行事曆」（設定 → App → 行事曆 → 行事曆帳號），再用瀏覽器打開 <https://calendar.google.com/calendar/syncselect>，勾選「計劃版」並儲存。Mac 的「行事曆」App 也是一樣的做法。

## 在自己電腦上預覽

網站用的是 JavaScript 模組，不能直接雙擊 `index.html` 打開，要用一個簡單的伺服器：

```bash
cd Calandar
python3 -m http.server 8000
```

然後打開 <http://localhost:8000/>。`localhost` 預設就在 Firebase 的授權網域裡，所以本機也能登入。

**想自己加一套主題**：打開 `js/themes.js`，照著其他主題的格式在 `THEMES` 裡加一筆（名稱、emoji、淺色和深色的顏色），再把它的 `id` 放進 `THEME_GROUPS` 的某個分類。

**更新網站**：直接改檔案就好，不用開新的資料夾。改完之後：
1. 想一個新的版本編號，例如日期加上當天第幾次：`2026-12-01-1`
2. 把這個編號填進三個地方：`js/update.js` 的 `APP_BUILD`、`latest.json` 的 `build`、`sw.js` 的 `VERSION`（前面加 `planner-`，例如 `planner-2026-12-01-1`）
3. commit 並 push

推上去一兩分鐘後，所有打開著的網站都會自動重新載入成新版（正在輸入或開著視窗時會先問）。以前的版本都留在 GitHub 的 commit 紀錄裡，需要的時候可以找回來。

## 常見問題

**按「用 Google 登入」沒反應，或說視窗被擋住**
瀏覽器擋住了彈出式視窗。請允許這個網站開啟彈出式視窗。LINE、Instagram 等 App 內建的瀏覽器常常會擋，請改用 Safari 或 Chrome 打開。

**登入時說這個網址還不能用來登入**
回到第 4 步，確認授權網域裡有 `coolalxeanderyi.github.io`。

**登入後說沒有權限讀寫資料**
回到第 5 步，確認 `firestore.rules` 的內容已經貼上並按了「發布」。

**右上角一直顯示「連線中」**
代表還連不到雲端，例如網路不穩，或 Firestore 資料庫還沒建立。這段期間的變更會先存在裝置上，連上之後自動同步。

**頁首出現「點一下同步日曆」**
Google 給網站的日曆通行證大約一小時就會過期，而這個網站沒有自己的伺服器可以在背後自動更新。有新的變更還沒送到 Google 日曆時就會出現這個按鈕，點一下、在小視窗裡確認，就會把變更送出去。

**出現「Google Calendar API 還沒啟用」**
回到第 7 步，確認 Google Calendar API 已經按了「啟用」。剛啟用可能要等幾分鐘才會生效。

**不想同步了，想把 Google 日曆裡的行程刪掉**
在網站的設定裡按「停止同步」。已經同步過去的行程會留在「計劃版」日曆裡，可以到 Google 日曆的設定裡把整個「計劃版」日曆刪除。

**更新之後還是看到舊版？**
打開著的網站會自己換成新版。如果是改成單一網址以前就開著的分頁（網址裡還有 `/v7/` 這種），重新整理一次就會回到首頁，之後就會自動更新了。

**怎麼加到手機主畫面？**
iPhone：用 Safari 打開網站，按下方的「分享」→「加入主畫面」。也可以安裝描述檔：在 iPhone 的 Safari 打開 <https://coolalxeanderyi.github.io/Calandar/iphone.mobileconfig> 下載，到「檔案」App 的「下載項目」點它，再到「設定」最上面的「已下載描述檔」按「安裝」（設定裡的「放到 iPhone 主畫面」有詳細步驟）。兩種方法結果一樣，都免費，不會過期。
Android：用 Chrome 打開，按右上角選單 →「加到主畫面」或「安裝應用程式」。
如果以前是從 `/v5/`、`/v7/` 這種網址加到主畫面的，請把舊的圖示刪掉，從 <https://coolalxeanderyi.github.io/Calandar/> 重新加一次。

**快速新增時，不想讓某些字被當成日期或時間？**
看一下輸入框下面的「會加上」：如果抓錯了，直接按「新增」之後再點開任務改就好，或是改用「新增任務」視窗（在電腦上按 <kbd>N</kbd>）一欄一欄填。

**標籤的顏色可以自己選嗎？**
有 8 種顏色，在設定的「標籤」裡點名稱左邊的圓點就會換下一個顏色。這 8 種顏色在淺色和深色模式都看得清楚，色盲也分得出相鄰的顏色。

**重複的任務怎麼只改某一次？**
每一次可以分開打勾。想改時間或日期的話，目前是整個系列一起改（在編輯視窗改「從哪天開始」、時間或星期幾）。

**資料存在哪裡？**
登入後存在你自己的 Firebase 專案（Firestore 的 `users/你的帳號ID/` 底下），只有你自己能讀寫。試用模式則只存在那台裝置的瀏覽器。設定裡可以隨時「匯出備份」成 JSON 檔；連接 Google 日曆之後，每天也會自動備份一份到你自己的 Google 雲端硬碟。
